## Instructions
1. Task 1: Load/collect the dataset and document its structure (columns, data types, size, and meaning).
2. Task 2: Clean the data (handle missing values, remove duplicates, fix formatting) and verify data quality.
3. Task 3: Perform EDA (basic stats, trends, outliers) and summarize key findings.
4. Task 4: Visualize insights with appropriate charts, clearly labeled and focused on takeaways.
5. Task 5: Deliver either a simple predictive model (train + evaluate + interpret) or an insight-based conclusion/recommendation.
